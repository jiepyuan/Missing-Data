# Repository Structure

This repository contains the code used to generate, analyze, and visualize the simulated missing data described in the manuscript, together with the code for the empirical example. It is organized into four major components:

1. `Empirical Data Code/`: code for the empirical example presented in the manuscript.
2. `Data Simulation/`: code for simulating data under the missing-data mechanisms considered in the manuscript.
3. `Analysis/`: code for handling the simulated incomplete data using different missing-data methods.
4. `Plot/`: code and output for summarizing and visualizing the simulation results.

The simulation study considers two big groups of missing-data types, referred to as `baseline` and `diffuse`. Within each group, separate workflows are provided for scenarios in which only the outcome `Y` is missing and scenarios in which `Y`, `X`, and `Z` are all subject to missingness.

---

## `Empirical Data Code/`

This folder contains the code used for the empirical example presented in the manuscript.

---

## `Data Simulation/`

This folder contains the code used to simulate incomplete data under the missing-data types described in the manuscript.

It is organized into two subfolders:

* `baseline/`: simulation code for the baseline missing-data types.
* `diffuse/`: simulation code for the diffuse missing-data types.

### `Data Simulation/baseline/`

The baseline setting includes the following scenarios.

#### Only `Y` is missing

* `Y_MCAR`
* `Y_MAR_X1`
* `Y_MNAR_Z1`
* `Y_MNAR_Self`

#### `Y`, `X`, and `Z` are missing

* `Y_MCAR_XZ_MCAR`
* `Y_MCAR_XZ_MNAR`
* `Y_MAR_X1_XZ_MCAR`
* `Y_MAR_X1_XZ_MNAR`
* `Y_MNAR_Z1_XZ_MCAR`
* `Y_MNAR_Z1_XZ_MNAR`
* `Y_MNAR_Self_XZ_MCAR`
* `Y_MNAR_Self_XZ_MNAR`

The folder contains the following principal scripts:

* `Generate.Y.miss.R`

  Generates incomplete data for the scenarios in which only `Y` is missing.

* `Generate.XYZ.miss.R`

  Generates incomplete data for the scenarios in which `Y`, `X`, and `Z` are all subject to missingness.

### `Data Simulation/diffuse/`

The diffuse setting includes the following scenarios.

#### Only `Y` is missing

* `Y_MAR_X1_X2`
* `Y_MNAR_Y_X1_X2`

#### `Y`, `X`, and `Z` are missing

* `Y_MAR_X1_X2_XZ_MCAR`
* `Y_MAR_X1_X2_XZ_MNAR`
* `Y_MNAR_Y_X1_X2_XZ_MCAR`
* `Y_MNAR_Y_X1_X2_XZ_MNAR`

The folder contains the following principal scripts:

* `Generate.Y.miss.R`

  Generates incomplete data for the scenarios in which only `Y` is missing.

* `Generate.XYZ.miss.R`

  Generates incomplete data for the scenarios in which `Y`, `X`, and `Z` are all subject to missingness.

## `Analysis/`

This folder contains the code used to analyze the incomplete data generated by the scripts in `Data Simulation/`.

Like `Data Simulation/`, it is organized into two main subfolders:

* `baseline/`: analyses for the baseline missing-data types.
* `diffuse/`: analyses for the diffuse missing-data types.

The missing-data types represented in these two folders are the same as those described for the corresponding `Data Simulation/` folders.

### `Analysis/baseline/` and `Analysis/diffuse/`

Each folder contains two missingness-specific subfolders:

* `Ymiss/`: analyses for scenarios in which only `Y` is missing.
* `XYZmiss/`: analyses for scenarios in which `Y`, `X`, and `Z` are missing.

Each of these folders is further organized by sample size:

* `n30/`: sample size of 30.
* `n50/`: sample size of 50.
* `n200/`: sample size of 200.
* `n500/`: sample size of 500.
* `n1000/`: sample size of 1,000.

For example, the `n30/` folder contains the following R scripts:

* `Analysis.R`

  Applies different missing-data analytical methods to the simulated incomplete data and organizes the resulting estimates and performance measures.

* `Simulation.Script.R`

  Runs the workflow in `Analysis.R` across different combinations of influential factors.

The `n50/`, `n200/`, `n500/`, and `n1000/` folders follow the same organization. The `baseline/` and `diffuse/` analysis folders also share the same overall structure.

---

## `Plot/`

This folder contains the code used to visualize the results produced by the analyses in `Analysis/`.

It is organized into two subfolders:

* `baseline/`: plots for the baseline simulation settings.
* `diffuse/`: plots for the diffuse simulation settings.

### `Plot/baseline/` and `Plot/diffuse/`

Each folder contains three subfolders:

* `Plot in Paper/`: code and output for the figures included in the manuscript.
* `Plot_Y_miss/`: figures for scenarios in which only `Y` is missing.
* `Plot_XYZ_miss/`: figures for scenarios in which `Y`, `X`, and `Z` are missing.

#### `Plot in Paper/`

This folder contains:

* `Code/`: R code used to generate the figures presented in the manuscript.
* `Plot/`: figures produced by the scripts in `Code/`.

#### `Plot_Y_miss/`

This folder contains two parameter-specific subfolders:

* `x1/`: plots for the first main-predictor parameter (x1).
* `x2/`: plots for the second main-predictor parameter (x2).

Each parameter folder contains four performance-measure subfolders:

* `relative bias/`: plots of relative bias.
* `ese/`: plots of empirical standard error (ESE).
* `mse/`: plots of mean squared error (MSE).
* `power/`: plots of statistical power.

Each performance-measure folder contains:

* `Plot.R`

  Generates the corresponding result plots.

* Plot output files produced by `Plot.R`.

#### `Plot_XYZ_miss/`

This folder follows the same parameter-specific and performance-measure organization as `Plot_Y_miss/`, but contains results for scenarios in which `Y`, `X`, and `Z` are all subject to missingness.

The `baseline/` and `diffuse/` plot folders share the same overall structure.
